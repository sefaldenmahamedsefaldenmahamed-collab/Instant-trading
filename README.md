# 🎯 قناص الزخم — Momentum Sniper

بوت تداول **Spot** متكامل لمنصة **Binance** متخصص في قنص العملات ذات الزخم العالي جداً (Breakout / Memecoins)، مع **لوحة تحكم حية (Live Dashboard)** بالعربية تعرض كل ما يفعله البوت لحظة بلحظة، وجاهز للنشر على **Render** بخطوات قليلة.

> ⚠️ **تحذير مخاطر**: هذا البوت أداة برمجية وليست نصيحة مالية. تداول العملات الرقمية عالي المخاطر وقد تخسر رأس مالك بالكامل. ابدأ دائماً بوضع المحاكاة (Paper) ثم Testnet، ولا تضع أموالاً لا تتحمل خسارتها.

---

## ✨ المزايا

| الميزة | الشرح |
|---|---|
| 🔥 **نقاط زخم مركبة (0–100)** | محرك تقييم من 10 عوامل موزونة: انفجار حجم 5د، زخم 5د/15د/ساعة/4س/24س، السيولة، RSI(15د)، ضجة اجتماعية، ضغط أوامر الشراء — مع **تفكيك شفاف لكل درجة** في اللوحة (زر «لماذا؟») |
| 🌐 **اكتشاف من خارج Binance** | كشط CoinGecko Trending + أكبر الصاعدين عالمياً + إشارات Reddit — العملة التي تتصدّر الترند خارج Binance تُفحص فوراً وتُقنص قبل أن يلتقطها الجميع، بشرط توفر زوج USDT والسيولة |
| 🚀 **قنص الإدراج الجديد** | مراقبة إعلانات Binance الرسمية ("Will List") + رصد فتح التداول عبر `exchangeInfo` — دخول خلال ثوانٍ من سرد العملة بأولوية وأحجام مخاطرة أصغر |
| 😨 **مؤشر الخوف والطمع** | قراءة Fear & Greed Index تلقائياً: طمع شديد (≥80) → رفع سقف الدخول، خوف شديد (≤20) → تجميد الدخول حماية من الانهيار الجماعي |
| 🧠 **التحليل الذاتي (Trade Autopsy)** | بعد كل صفقة مغلقة يكتب البوت تقريراً: لماذا دخلت؟ لماذا خرجت؟ — ويعدّل معاييره ذاتياً (حد الدخول، إحكام الترailing، درع FOMO) ضمن حدود آمنة، وكل تعديل يظهر في اللوحة |
| 🛡 **إدارة مخاطر صارمة** | درع FOMO (رفض شراء عملة ارتفعت أكثر من +80%)، رفض الشمعة العمودية (+45% في ساعة)، وقف خسارة صارم −12%، وقف متحرك يُسلّح عند +30%، سلّم أهداف +100/+250/+500% ببيع متدرج، خروج احترازي عند انهيار الزخم، حد أقصى للصفقات المتزامنة واليومية، فحص فرق العرض/الطلب |
| 📊 **لوحة حية عربية RTL** | بث لحظي عبر WebSocket: قيمة المحفظة ومنحناها، الصفقات المفتوحة مع حالة الحماية، لوحة صدارة الزخم، البث الكامل لكل قرار، سجل الصفقات، رادار الإدراج، مرفوضات حكيمة، إعدادات حية |
| 🔁 **ثلاثة أوضاع تشغيل** | `paper` (محاكاة بأسعار حية — بدون أي مفاتيح) / `testnet` (Binance التجريبي) / `live` (حقيقي) — بمتغير واحد `MODE` |

## 🚀 التشغيل المحلي (دقيقتان)

```bash
cd momentum-sniper
python -m venv .venv && source .venv/bin/activate      # ويندوز: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env        # الإعدادات الافتراضية تعمل بوضع المحاكاة مباشرة
python run.py
```

افتح المتصفح على: **http://localhost:8000** — سترى البوت يفحص السوق ويعرض كل شيء في اللوحة. في وضع `paper` لا تحتاج أي مفاتيح API إطلاقاً.

## 📋 أهم متغيرات البيئة

| المتغير | الافتراضي | الشرح |
|---|---|---|
| `MODE` | `paper` | `paper` محاكاة / `testnet` تجريبي / `live` حقيقي |
| `BINANCE_API_KEY` / `BINANCE_API_SECRET` | فارغ | مطلوبان فقط لـ testnet و live |
| `PAPER_START_BALANCE` | `100` | رأس مال المحاكاة |
| `TRADE_ALLOCATION_PCT` | `10` | نسبة كل صفقة من الرصيد الحر (%) |
| `MAX_CONCURRENT_TRADES` | `3` | أقصى صفقات مفتوحة معاً |
| `MAX_TRADES_PER_DAY` | `6` | أقصى صفقات يومياً |
| `HARD_STOP_LOSS_PCT` | `-12` | وقف الخسارة الصارم (%) |
| `TP_LADDER` | `100:30,250:30,500:40` | سلّم الأهداف: ارتفاع% : نسبة بيع% |
| `TRAIL_TRIGGER_PCT` / `TRAIL_DROP_PCT` | `30` / `15` | تسليح الترailing وهامش الحماية |
| `ENTRY_SCORE_THRESHOLD` | `78` | أدنى درجة زخم للدخول |
| `FOMO_BLOCK_24H_PCT` | `80` | رفض شراء عملة ارتفعت أكثر من هذا |
| `MIN_QUOTE_VOLUME_24H` | `2000000` | أدنى سيولة يومية (USDT) |
| `SCAN_INTERVAL_SEC` | `60` | دورية فحص السوق |
| `NEW_LISTING_SNIPE` | `true` | قنص الإدراج الجديد |
| `AUTOPSY_LEARNING` | `true` | التحليل الذاتي والتعلم |
| `REDDIT_ENABLED` | `true` | إشارات Reddit (بدون مفاتيح) |
| `X_BEARER_TOKEN` | فارغ | اختياري: X/Twitter API مدفوع |

القائمة الكاملة مع الشرح داخل `.env.example`.

## ☁️ النشر على Render (خطوة بخطوة)

### الطريقة الأسهل — Blueprint
1. ارفع المشروع إلى مستودع **GitHub** جديد (لا ترفع ملف `.env` أبداً — موجود في `.gitignore`).
2. من لوحة Render: **New + → Blueprint** واختر المستودع — سيقرأ `render.yaml` تلقائياً.
3. أضف الأسرار من تبويب **Environment** في الخدمة (لن تُرفع لـ GitHub):
   - `BINANCE_API_KEY` و `BINANCE_API_SECRET` (فقط إن كنت ستشغّل testnet/live)
4. اضغط **Apply** — بعد دقيقة سيعمل البوت على `https://your-app.onrender.com` واللوحة على الصفحة الرئيسية.

### الطريقة اليدوية
- **New + → Web Service** → اختر المستودع
- Runtime: **Python 3** · Build: `pip install -r requirements.txt` · Start: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
- Health Check Path: `/health`
- أضف متغيرات البيئة من الجدول أعلاه.

> 💡 الخطة المجانية على Render تُسبِن الخدمة بعد فترة خمول — غير مناسبة لبوت 24/7. استخدم **Starter** أو أعلى.
> 💡 لحفظ سجل الصفقات بعد إعادة النشر، أضف **Disk** على المسار `/app/data` (من تبويب Disks) واترك `DB_PATH=data/bot.db`.

## 🔑 إنشاء مفاتيح Binance (لوضع live)

1. Binance → **Account → API Management** → Create API.
2. فعّل **Enable Spot Trading** فقط.
3. ⛔ **لا تفعّل السحب (Withdrawals) إطلاقاً**.
4. أضف IP سيرفر Render في **IP Restriction** إن أمكن.
5. ضع المفاتيح في متغيرات بيئة Render فقط — لا تضعها في الكود أبداً.

لوضع `testnet`: مفاتيح مجانية من https://testnet.binance.vision

## ❓ أسئلة شائعة

- **أين تيليجرام؟** حُذف نهائياً بناءً على اختيارك — كل الإشعارات في اللوحة الحية.
- **هل يعمل بدون مفاتيح؟** نعم، وضع `paper` كامل بدون أي مفاتيح وبأسعار حية.
- **أضفت عملة جديدة لبينانس، هل يقنصها؟** نعم — يرصدها من إعلانات Binance ويلتقط لحظة فتح التداول عبر `exchangeInfo`.
- **كيف أعطّل التعلم الذاتي؟** `AUTOPSY_LEARNING=false`.
- **اللوحة لا تفتح بعد النشر؟** تأكد من Health Check `/health` وراجع Logs — غالباً خطأ في متغير بيئة.

## 🧰 ملاحظات تشغيلية

- البوت يحترم حدود Binance API تلقائياً (انتظار عند 429/418) — لا تعدّل `SCAN_INTERVAL_SEC` تحت 30 ثانية.
- عند إيقاف البوت وإعادة تشغيله: الصفقات المفتوحة تُستأنف من الذاكرة الجديدة (لا تُستعاد من القاعدة بعد إعادة النشر) — في وضع live اجعل الإيقاف قصيراً أو أغلق يدوياً من Binance إن لزم.
- الرسائل في اللوحة كلها تُحفظ في SQLite (`data/bot.db`) لمراجعتها لاحقاً.
